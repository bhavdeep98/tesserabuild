The Closing Confidence Score is a signal-strength meter

Every system a builder runs is already broadcasting. BuildPro reports the pour, Encompass the underwrite, Qualia the title search. Home Passport never asks anyone for a status — it listens. Each signal lights a milestone; the meter reads how strongly one home's closing is coming through.

Silence is information

Each home carries 51 milestone receivers, one per signal type in the taxonomy. A milestone starts UNKNOWN and only a real signal from a source system can flip it to COMPLETE. Every receiver counts in the denominator from day one — so an untouched milestone quietly pulls the score down. The meter can't be talked up in a status meeting; it only rises when the systems of record actually broadcast.

Divisions can override them per market, and when USE_ML_SCORING is on, a trained model replaces this mix entirely and explains itself through ranked SHAP factors instead.

Interference

Two things degrade a broadcast: a transmitter going dark, and time running out. The meter penalizes both.

Static — a tower goes quiet −5 / source

When a source system hasn't been heard from past its freshness window, its whole domain is flying blind. Every stale source subtracts 5 points — not because anything is known to be wrong, but because nothing is known at all.

Drag — the date slips past −10 − 8/wk

The moment an active home passes its target close date, it takes a 10-point hit, plus 8 more for every week overdue. At $670/day in carrying costs, an overdue home should never look calm on a dashboard.

Reading the meter

The number maps to three bands. The point isn't the score itself — it's that the category breakdown and penalty chips tell you exactly which tower to fix before a delay cascades across systems.

75–100HEALTHY

Strong signal on every domain. Leave the team alone.

50–74AT_RISK

Signal weakening somewhere specific. Act on the weakest category now, while it's one problem.

0–49CRITICAL

Escalate. Delay is compounding across domains — this is where cancellations come from.
